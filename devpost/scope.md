# DeadlineGuard
Turn competition rules into an evidence-backed action checklist.

## The Unique Kernel
Every detected requirement retains its original wording, and source verification is tracked separately from task completion. The entrant can see both what remains to do and what remains to verify.

## Who It's For
A beginner entering an online competition who needs to make sense of lengthy official rules while building their entry.

## The Core Loop
Paste rules, scan them, review source evidence, add omissions, track completion, and export the checklist or a manually confirmed deadline.

## Inspiration & Identity
Calm, readable planning desk. Green and warm neutral colors are agent-selected design choices under the user's request to handle implementation.

## Why This Matters to the Learner
The user is preparing a Build With AI: Basics entry and asked for technical help with minimal involvement.

## What "Working" Looks Like
A user scans a fictional rules document, verifies a repository requirement, marks it complete, reloads without losing progress, and exports useful files.

## The POC Boundary
Browser-local English text scanner, evidence review, three requirement categories, completion tracking, manual additions, Markdown export, print, and calendar file export.

## Later
AI-assisted semantic extraction, URL ingestion, multiple saved competitions, change monitoring, broader timezone selection.

## Explicitly Cut
No automated eligibility verdicts, automatic website scraping, or background notifications. The proof of concept focuses on reviewable checklist creation. Calendar reminders require importing an exported file.

## Decision provenance
The prior chat proposed the competition-rule checklist idea; the user said "Proceed" and asked this agent to build and test it. Specific design and implementation choices are agent assumptions, not claims of user preferences. Final review remains pending.
